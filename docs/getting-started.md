# Getting Started

QuackViz is a local-first browser app for loading analytical files, querying them with DuckDB-WASM, and turning results into charts, dashboards, reports, maps, and portable local packages.

Primary workflow:

1. Add data from a local file or direct URL.
2. Inspect the detected table, schema, and preview rows.
3. Run a starter query or write SQL.
4. Build and save a visualization.
5. Combine saved work into a dashboard or report.
6. Export a local backup, report, snapshot, or standalone package.

AI is optional. Manual import, SQL, visualization, dashboard, report, map, and export workflows work without AI.
