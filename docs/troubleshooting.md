# Troubleshooting

## Beta limitations

- Local files may need to be re-imported after reload.
- Browser memory limits apply.
- URL import depends on CORS.
- AI requires an external OpenRouter provider.
- Remote basemaps require network access.
- Some map exports depend on tile-server CORS.
- Firefox and WebKit support may differ.
- No server-backed sharing or collaboration is implemented.

QuackViz does not send usage analytics.
